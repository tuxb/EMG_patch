This is the EMG module implementing the explicit modified-gradient (EMG) method within the gizmo-public code (https://github.com/pfhopkins/gizmo-public).

Replace files with identical names inside the original gizmo-public code using those from this module, and fully substitute the native hydro folder with hydro-r folder. 

In addition, this module contains initial condition files for the Orszag-Tang vortex and field-loop numerical test cases, as well as compilation configuration files.
